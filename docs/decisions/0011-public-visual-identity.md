# Identidad visual pública

El catálogo conserva una superficie clara, tipografía sobria, acentos de marca y tarjetas de inventario orientadas a comparación. Los controles conservan etiquetas accesibles, foco de teclado y estados explícitos de carga, error y vacío. La página de detalle adelantada solo muestra información publicada mínima; no anticipa funcionalidades comerciales de fases posteriores.
